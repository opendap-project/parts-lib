## Summary

The GT911 is a capacitive touch controller for up to 5 concurrent touches, with an internal 1.8 V LDO, embedded flash and a standard I²C slave interface at 1.8–3.3 V host levels (GT911 Rev.09 §1–§2, pp. 4–5). In the T1 it is part of the Focus LCDs E35GH-I-MW800-CB display module of the touch faceplate (BOM v1 line 82, decided with the display; see [`Focus-LCDs/E35GH-I-MW800-CB.md`](../Focus-LCDs/E35GH-I-MW800-CB.md)). It is reached through the module's 6-pin CTP tail on faceplate I2C3 (3.3 V, VCCIO5), at 7-bit address 0x5D or 0x14.

## Application circuit and required passives

Sample schematic (p. 18, §9), for reference. On the T1 these parts sit on the display module, not on OpenDAP boards:

- 2.2 µF on AVDD28, AVDD18, DVDD12 and VDDIO (C1–C4); ceramic X7R recommended (p. 18 note).
- /RSTB: 10 kΩ pull-up to VDDIO, with a 10 nF capacitor to ground (C5).
- INT: an RC (680 Ω, 1 nF) on INT, "to enable Gesture wake-up function".
- Sensor_OPT1/OPT2 straps select one of 6 module IDs.
- I²C pull-ups on the module, to be removed if the host bus already has pull-ups (p. 18 note). Their value is hard to read at the available resolution (**UNVERIFIED**).
- VDDIO sets the logic level: connected to AVDD gives AVDD logic, otherwise 1.8 V (p. 18 note; p. 6 pin 21).

How the E35GH module ties VDDIO (to AVDD or floating), and whether it fits the on-module pull-ups and the RST/INT RC, is not stated in the Focus spec (**UNVERIFIED**). The I/O level the faceplate sees depends on it.

## Interfaces and timing

**I²C** (p. 9, §6.1): slave only; rate at or below 400 kbit/s strongly recommended. The same timing applies at 1.8 V and 3.3 V host voltage (400 kbit/s, 2 kΩ pull-up):

| Parameter | Symbol | Min | Unit |
|---|---|---|---|
| SCL low period | tlo | 1.3 | µs |
| SCL high period | thi | 0.6 | µs |
| SCL setup for START | tst1 | 0.6 | µs |
| SCL setup for STOP | tst3 | 0.6 | µs |
| SCL hold for START | thd1 | 0.6 | µs |
| SDA setup | tst2 | 0.1 | µs |
| SDA hold | thd2 | 0 | µs |

Registers use 16-bit addresses with auto-increment (pp. 11–12).

**Address selection** (p. 9; p. 10 diagrams; p. 11 top diagram). Two addresses are given in 8-bit form, 0xBA/0xBB and 0x28/0x29, which are 7-bit 0x5D and 0x14. The host selects one by the INT level while RESET rises:

1. RESET output low and INT output low.
2. INT set to the address level: high for 0x28/0x29 (0x14), low for 0xBA/0xBB (0x5D), at least 100 µs before RESET rises.
3. RESET driven high; INT held for at least 5 ms after RESET rises.
4. INT driven low for at least 50 ms.
5. INT released to input (floating). The GT911 then drives INT as its interrupt output.

**Power-on timing** (p. 10, first diagram):

| Step | Value |
|---|---|
| AVDD to VDDIO | T1 ≥ 0 µs |
| VDDIO to INT address select | T2 > 10 ms |
| INT select to RESET rising | T7 > 100 µs |
| RESET rising to end of address select | T8 > 5 ms |
| INT output low after select | T3 > 50 ms, then host sets INT as input |
| First touch scan after reset | T9 < 100 ms |
| Scan period | 5–20 ms |

**Host reset** (p. 10, second diagram): RESET low T1 > 100 µs; INT set T2 > 100 µs before RESET rises; T3 > 5 ms; INT low T4 > 50 ms; first scan T5 < 100 ms.

**Interrupt** (p. 16, §8.2): one INT pulse per scan cycle while touched. The polarity is set by the configuration "INT" bit: 0 = rising edge, 1 = falling edge. Gesture mode wakes the host with an INT pulse longer than 250 µs, or a high level (p. 15).

- Mainline input driver `goodix` (`drivers/input/touchscreen/goodix.c`, Kconfig `TOUCHSCREEN_GOODIX`), compatible `goodix,gt911`. The BOM records *mainline + Debian*.

## Design notes for the T1

- **Supply range.** AVDD28 2.8–3.3 V recommended, 3.47 V absolute maximum (p. 19). FP_3V3 (BOM line 82) is inside the range but at its top. A 3.3 V rail with more than about +5 % tolerance would break the absolute maximum.
- **Address.** Use 0x5D (INT low at reset) or 0x14 (INT high). Neither clashes with the VEML6030 (0x10) on I2C3 (BOM §4.2). The HID controller address on I2C3 must also avoid both (**UNVERIFIED**, not yet assigned).
- **INT doubles as a strap.** The SoC GPIO driving INT must be an output during reset and an input afterwards, and nothing else on the faceplate may drive or strongly pull it (BOM line 82).
- **Logic level.** I²C3 runs at 3.3 V (VCCIO5). That is correct only if the module ties GT911 VDDIO to AVDD. If VDDIO floats (1.8 V logic), VIH = 0.75 × VDDIO is still met by a 3.3 V host, but a 3.3 V pull-up would exceed VDDIO + 0.3 V on the GT911 pins (p. 20). Confirm the module's VDDIO strap with Focus LCDs before the faceplate schematic (**UNVERIFIED**).
- **Sleep for suspend.** Sleep mode (70–120 µA, p. 20) requires INT low before the command, and wake needs INT high for 2–5 ms, at least 58 ms after the sleep command (p. 15). If FP_3V3 is gated off in suspend instead, the full power-on sequence above applies at resume.
- **Firmware and configuration.** The GT911 holds its configuration in flash (p. 4). The configuration shipped by Focus LCDs determines resolution, orientation and INT polarity; reading it out on a sample is required (**UNVERIFIED**).
